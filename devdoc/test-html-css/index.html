Writer 预览样式与大纲栏 Demo

这是从 writer-computer 迁移而来的预览观感：文字栏 734px 居中、16px / 1.8 行高、accent 橙链接、 圆角代码 chip、muted 渲染标记。右侧是 大纲栏——把鼠标移到 右边缘的 tick 条上试试。

排版

标题层级

H1 为 1.6em、H2 为 1.4em、H3 为 1.2em，加粗但不改字重之外的东西； H4 及以下继承正文字号。标题不需要悬挂 # 符号——那是编辑态 的 caret 行为，静态页里它不存在。

一个 H4 标题

可以看到 H4 字号与正文一致，仅加粗区分。正文里可以有 重点、 斜体强调，以及 带下划线的链接。

引用

引用块用 0.3em 的竖线锚定在左侧，文字使用 muted 色调，与正文的 secondary 拉开层次。

嵌套段落保持同一竖线，这是静态 CSS 的天然优势——不需要 Writer 里那套绝对定位装饰。

代码

行内代码

行内代码是 mono 字体 + --code-bg 底色的圆角 chip， 关闭了连字（calt 0）。写路径 apps/desktop/src-tauri/src/commands/fs.rs 这类内容时不会被连字干扰。

代码块与语法高亮

代码块不带语言标签和拷贝按钮（Writer 把它们藏了），色板取自 Writer 的 oklch 语法色：

// fetchHeadings 拉取页面并提取全部标题
func fetchHeadings(url string) ([]string, error) {
    resp, err := http.Get(url)
    if err != nil {
        return nil, fmt.Errorf("请求 %s 失败: %w", url, err)
    }
    defer resp.Body.Close()
    if resp.StatusCode != http.StatusOK {
        return nil, errors.New("HTTP " + resp.Status)
    }
    return extractHeadings(resp.Body)
}

链接

链接统一走 accent 色 + 下划线。回到排版、 去看代码。右键大纲栏里的任何一行，可以复制 [标题](#锚点) 格式的链接——与 Writer 的"复制标题链接"一致。

结语

这份 demo 覆盖了两块内容的可迁移性：样式部分是"翻译式"移植（决策保留、 CodeMirror 专属选择器丢弃）；大纲栏部分是 CSS 几乎 1:1 照搬 + 原生 JS 重写（数据源从 CodeMirror 文档换成现成 DOM）。右侧 tick 条在滚动时 自动高亮当前章节，点击即可跳转。

试试看：滚动页面观察 tick 高亮 → 悬停右缘展开大纲 → 点击跳转 → 右键复制链接。
